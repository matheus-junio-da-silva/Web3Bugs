# Contribution Guidelines

We welcome contributions to the Web3Bugs-certora dataset, including:

+ Suggesting new security-analysis references.
+ Adding bugs and findings from Certora projects collected in [PropertyGPT](https://github.com/matheus-junio-da-silva/PropertyGPT).
+ Adding Certora project snapshots and specifications.
+ Suggesting improvements to the classification standard.
+ Correcting mislabeled bugs or severities.
+ Filling in missing project metadata in `results/contests.csv`.

For most contributions, submit a pull request for review.

When adding a project, use its source under the [PropertyGPT Certora projects](https://github.com/matheus-junio-da-silva/PropertyGPT/tree/main/certora_projects), preserve the Web3Bugs dataset structure, and record all report findings regardless of severity.

See [`docs/modifications.md`](modifications.md) for the deliberate differences from the original Web3Bugs dataset.
