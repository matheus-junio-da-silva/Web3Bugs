```cvl
rule executionOnlyIfQuoromReachedAndVoteSucceeded(uint256 pId, env e, method f){
    bool isExecutedBefore = isExecuted(pId);
    bool quorumReachedBefore = quorumReached(e, pId);
    bool voteSucceededBefore = voteSucceeded(pId);
    
    calldataarg args;
    f(e, args);

    assert (!isExecutedBefore && isExecutedAfter) => (quorumReachedBefore && voteSucceededBefore), "quorum was changed";
}
```

## Predicado e condição de falha
As assertions textuais dentro deste intervalo são: `(!isExecutedBefore && isExecutedAfter) => (quorumReachedBefore && voteSucceededBefore), "quorum was changed"`. A refutação exigiria um caminho executável, admitido pelos `require`, em que ao menos uma seja falsa.
- Predicado da matriz semântica: `(!isExecutedBefore && isExecutedAfter) => (quorumReachedBefore && voteSucceededBefore),`.
- Sequência de chamadas: `isExecuted; quorumReached; voteSucceeded; f`. Preservar ordem e semântica de revert, inclusive `lastReverted`.
