```cvl
rule privilegedOnlyTimelock(method f, uint256 newQuorumNumerator){
    env e;
    calldataarg arg;
    uint256 timelockBefore = timelock(e);

    f(e, arg);

    uint256 timelockAfter = timelock(e);

}
```

## Predicado e condição de falha
As assertions textuais dentro deste intervalo são: `timelockBefore != timelockAfter => e.msg.sender == timelockBefore, "non privileged user changed timelock"`. A refutação exigiria um caminho executável, admitido pelos `require`, em que ao menos uma seja falsa.
- Predicado da matriz semântica: `timelockBefore != timelockAfter => e.msg.sender == timelockBefore,`.
- Sequência de chamadas: `timelock; f`. Preservar ordem e semântica de revert, inclusive `lastReverted`.
