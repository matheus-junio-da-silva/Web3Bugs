```cvl
rule onlyProposer(method f, env e) filtered { f -> f.selector == schedule(address, uint256, bytes, bytes32, bytes32, uint256).selector
                                                    || f.selector == scheduleBatch(address[], uint256[], bytes[], bytes32, bytes32, uint256).selector } {

```

## Predicado e condição de falha
As assertions textuais dentro deste intervalo são: `isCheckRoleReverted => isScheduleReverted, "Enemy was detected"`. A refutação exigiria um caminho executável, admitido pelos `require`, em que ao menos uma seja falsa.
- Predicado da matriz semântica: `isCheckRoleReverted => isScheduleReverted,`.
- Sequência de chamadas: `schedule; scheduleBatch; _checkRole; PROPOSER_ROLE; f`. Preservar ordem e semântica de revert, inclusive `lastReverted`.
