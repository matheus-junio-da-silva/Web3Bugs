# P01 — Methods, visibility, return types

**Somente planejamento, não migração.**
The eight historical CVL specs and extracted prerequisites contain older methods blocks. CVL2 requires function and semicolon, and internal/external. A possible syntactic change like mint(address) -> function mint(address) external; depends on exact ABI, return, receiver and summaries. E-A01/E-A03.
