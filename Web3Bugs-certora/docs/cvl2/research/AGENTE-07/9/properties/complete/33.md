## Literal rule/invariant and falsification
```cvl
rule no_double_upvote(uint256 p, address u) {
	uint256 _upvotes = getUpvotes(p);
	uint256 _usersUpvotedProposal = getUpvotedProposal(u);
	env e;
	require e.msg.sender == u && u != 0; // note that the sender is the signer here
    require accounts.voteSignerToAccount(u) == u;
	uint256 lesser;
    uint256 greater;
	upvote(e, p, lesser, greater);
	uint256 upvotes_ = getUpvotes(p);

    uint voteRecordP;
    uint voteRecordW;
    voteRecordP, voteRecordW = getUpvoteRecord(u);
    require upvoteInv(voteRecordP, voteRecordW);
	assert _usersUpvotedProposal == p => upvotes_ <= _upvotes,
		"Upvotes increased from ${_upvotes} to ${upvotes_} even though upvoted by user $u who already upvoted $p";
}

```
- Key predicate/asserter lines: "require e.msg.sender == u && u != 0; // note that the sender is the signer here"; "require accounts.voteSignerToAccount(u) == u;"; "assert _usersUpvotedProposal == p => upvotes_ <= _upvotes,".
- Falsification requires admissible require/method filter and false assert or invariant under relevant state; not automatically a reachable target action. Original catalog detection intent: A second upvote from a previously upvoting account must not increase that proposal's upvote total..
