## Literal rule/invariant and falsification
```cvl
rule approved_proposals_invariants(method f, uint256 p) filtered { f -> !f.isView } {
	env _e;
	env eF;
	env e_;

	// Existence depends on timestamp, and we assume we are well past 0
	require e_.block.timestamp >= eF.block.timestamp
			&& eF.block.timestamp >= _e.block.timestamp
			&& _e.block.timestamp > 0;

	bool _doesProposalExist = proposalExists(_e,p);
	bool _isApprovedProposal = isApproved(p);

	require _isApprovedProposal => _doesProposalExist; // if a proposal is approved, it must be existent

	calldataarg arg;
	require !f.isView;
	sinvoke f(eF,arg);

	bool doesProposalExist_ = proposalExists(e_,p);
	bool isApprovedProposal_ = isApproved(p);

	assert isApprovedProposal_ => doesProposalExist_, "An approved proposal must exist";
	assert _isApprovedProposal => isApprovedProposal_ || !doesProposalExist_, "An approved proposal cannot be disapproved if it still exists";
}

```
- Key predicate/asserter lines: "require _isApprovedProposal => _doesProposalExist; // if a proposal is approved, it must be existent"; "assert isApprovedProposal_ => doesProposalExist_, \"An approved proposal must exist\";"; "assert _isApprovedProposal => isApprovedProposal_ || !doesProposalExist_, \"An approved proposal cannot be disapproved if it still exists\";".
- Falsification requires admissible require/method filter and false assert or invariant under relevant state; not automatically a reachable target action. Original catalog detection intent: Approval must not result in nonexistent proposals or be reversed while a proposal still exists..
