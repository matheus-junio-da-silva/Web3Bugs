## Literal rule/invariant and falsification
```cvl
rule only_initializer_changes_initialized_field(method f) {
	env _e;
	env eF;
	env e_;

	bool _isInitialized = sinvoke initialized(_e);
	require(f.selector != initialize(address,uint256).selector);
	calldataarg arg;
	invoke f(eF,arg);
	bool isInitialized_ = sinvoke initialized(e_);
	assert(
    _isInitialized == isInitialized_,
    "Method $f is not expected to change initialization field from ${_isInitialized} to ${isInitialized_}"
  );
}

```
- Key predicate/asserter lines: "require(f.selector != initialize(address,uint256).selector);"; "assert("; "_isInitialized == isInitialized_,".
- Falsification requires admissible require/method filter and false assert or invariant under relevant state; not automatically a reachable target action. Original catalog detection intent: Only initialize is permitted to change the initialized field..
