## Literal property and counterexample model
```cvl
rule nonspenderCantReduceBalance(address nonspender, method f) {
  require(!isSpender(nonspender));
  require(!isExchangeSpender(nonspender));
  require(getExchangeAddress() != nonspender);

  uint256 balanceBefore = contractBalance();

  env e;
  require(e.msg.sender == nonspender);
  calldataarg arg;
  f(e, arg);

  uint256 balanceAfter = contractBalance();

  if (f.isFallback) {
    assert balanceAfter >= balanceBefore;
  } else {
    assert balanceAfter == balanceBefore;
  }
}

```
- Assertions/predicate clauses: "require(getExchangeAddress() != nonspender);"; "require(e.msg.sender == nonspender);"; "assert balanceAfter >= balanceBefore;"; "assert balanceAfter == balanceBefore;".
- False assert under the actual requires/selector filters or false invariant on an admitted state is necessary for violation; do not assume achievable transaction trace. Catalog intent: An address that is neither spender nor exchange must not decrease the reserve's balance through a fallback call, nor change it at all through other calls.
