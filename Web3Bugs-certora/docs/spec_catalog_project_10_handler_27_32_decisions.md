**Decision criterion:** all six source rules use `arbitrary(f)` (method f) without the `!isHandler()` exclusion of proxy-only rules #21–24. Therefore **none** of these handler contexts can be marked technically N/A from the visible CVL. The PDF column “Violating functions: None” means only that the report does not list a violating function in that cell; alongside 🔎 it does **not** certify an independent `VERIFIED` Prover result. The report does not assign reproducible source/target-specific individual results.

**Separate artifact decision:** a handler target changes `currentContract`, enumerated methods and injected getters; thus every applicable target would require a separate source/target evidence record to claim exhaustive replay. But a `N.spec` copied blindly from the generic ProxyHarness with unresolved imports, missing targets and injected symbols would be misleading. The 138 rows below are **candidate target-specific records blocked on reconstruction**; they are not indexed as the 128 existing examples and do not carry a newly invented Result. This is an explicit coverage blocker, not a successful completion or an N/A waiver.
