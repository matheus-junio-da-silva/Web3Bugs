## Report notation (PDF page 3)

- `✔`: verified on the latest commit.
- `✔*`: verified on a simplified code version **ignoring rounding errors**.
- `✍`: not formally specified yet.
- `🔁`: only applicable to a future code version with interest redirection.
- Rounding tolerance `ε` is restricted relative to `normalizedIncome()/ray` in the report; source rules may encode stricter exact equations.

## Main issues relevant to interpretation (PDF pages 1–3)

<a id="stable-additive-mint"></a>
**Medium, stable debt additive mint:** The report's issue table expressly names `Additive mint (Stable debt token)` and attributes an error to rounding during conversions at high conversion rates. It states that the mitigation avoids transfer on mint/burn of zero stable debt tokens. This is a real historic report finding, independent of any assignment to a particular supplied CVL file. Item #14 in the formal-property section is marked `✔*`, while the exact preserved `additiveMint` rule assumes zero stable rate and operates with an interest-free harness. The report does not show that this exact constrained rule produced or directly supported the issue; for example 6 Detection Outcome is `NOT_STATED`, with the historical finding separately retained as AV2-01 in `results/bugs.csv`.

Other reported issues include an incorrect DebtToken totalSupply due to missing interest accumulation, AToken burn rounding, user-debt and balance growth under interest redirection, interest-related division by zero, liquidation health factor, and collateral withdrawal. The report does not establish an exact source-rule-to-token match for every such issue. No automatic finding attribution is made to other Project 12 source instances.

## Historical reconstruction limits

The report confirms latest-commit verified status, not an outcome of a modern Certora Prover invocation. `✔*` is never recorded as an unqualified full-code proof. Source-level methods may differ from report prose, and missing original run flags/configuration prevent claiming exact replay.
