## Motivation

This arbitrary-non-view-function probe detects any change in an action-set state but is over-restrictive: normal execute and cancel calls legitimately cause Queued-to-Executed and Queued-to-Canceled transitions.

## Reconstructed methodology

The following reasoning is reconstructed from the source property, available Solidity code, and the public report; it is not presented as private auditor reasoning.

1. Read an action-set state.
2. Call an arbitrary non-view method.
3. Read the state again and assert equality, even though legitimate execute/cancel transitions may falsify it; treat this as a diagnostic, not a sound general security invariant.
