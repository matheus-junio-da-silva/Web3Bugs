**What the original assertion actually requires.** e1.msg.sender != e2.msg.sender => lastReverted

**Legitimate state changes.** An authorized origin can queue and update _actionsSets/_actionsSetCounter/_queuedActions; an unauthorized second sender should revert. The L2 rule instead calls missing queue2.
