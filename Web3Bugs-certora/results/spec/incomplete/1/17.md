## Motivation

The property is intended to detect reuse/reincarnation of a historical non-queued action-set ID after a new queue operation.

## Reconstructed methodology

The following reasoning is reconstructed from the source property, available Solidity code, and the public report; it is not presented as private auditor reasoning.

1. Assume a historical ID is not queued.
2. Queue another action set.
3. Assert that the historical ID did not become queued again.
