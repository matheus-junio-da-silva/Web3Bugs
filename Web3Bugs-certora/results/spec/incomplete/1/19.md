**What the original assertion actually requires.** count1 < max_uint => count2 == count1+1

**Legitimate state changes.** One successful queue may add actions and queued hashes while increasing the set counter exactly once. CVL has count1 < max_uint to avoid the wrap case.

**Concrete counterexample that would falsify the rule.** After a successful queue, count2 is not count1 + 1 although count1 < max_uint.
