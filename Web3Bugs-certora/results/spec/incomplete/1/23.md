## Motivation

The property is intended to detect duplicate action identity when equal action sets obtain the same execution time.

## Reconstructed methodology

The following reasoning is reconstructed from the source property, available Solidity code, and the public report; it is not presented as private auditor reasoning.

1. Queue identical action arguments at an earlier block.
2. Change the delay.
3. Try the same arguments at a later block.
4. If computed execution times are equal, require the second queue to revert.
