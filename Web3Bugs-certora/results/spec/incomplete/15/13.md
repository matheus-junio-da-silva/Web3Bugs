## Reconstructed methodology

The following reasoning is reconstructed from the source property, available Solidity code, and the public report; it is not presented as private auditor reasoning.

1. Track touched _assets and _assetsState positions with ghosts and storage hooks.
2. For a symbolic index i, if i is below getAssetsLength, read getAsset(i).
3. Require getAssetState for that address to be true.
4. Filter executeEmergencyAction from preservation and constrain the ghost initial-state model in the preserved block.

A counterexample would therefore show: some in-range asset returned by getAsset(i) is marked inactive.
