## Motivation

Require an active nonzero asset flag to correspond back to the same asset at its reverse-mapped array position.

## Reconstructed methodology

The following reasoning is reconstructed from the source property, available Solidity code, and the public report; it is not presented as private auditor reasoning.

1. Track array values and reverse indices with ghosts/hooks.
2. For a symbolic address val, test getAssetState(val).
3. If active, require getAsset(reverseMap[val]) to equal val, except for the explicit val == 0 allowance.
4. Filter executeEmergencyAction and bound getAssetsLength in preservation.

A counterexample would therefore show: a nonzero address is marked active but its reverse-mapped array slot contains a different address.
