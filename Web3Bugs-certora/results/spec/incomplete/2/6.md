## Motivation

Maintain two-way consistency between the mirrored membership flag and array representation across preserved methods.

## Reconstructed methodology

The following reasoning is reconstructed from the source property, available Solidity code, and the public report; it is not presented as private auditor reasoning.

1. Track _assets length, array values, reverse indices, and _assetsState through ghosts and storage hooks.
2. Assert every flagged address resolves to an in-range array slot containing that address.
3. Assert every in-range mirrored array element has its flag set.
4. Filter executeEmergencyAction from preservation checks.
5. During preservation, require uniqueArray and a bounded getAssetsLength value.

A counterexample would therefore show: an active flag points to no matching in-range array entry, or an in-range array entry is not marked active.
